# Учебные приложения

Два независимых проекта:

- [library](library/README.md) — библиотека, вариант 2.
- [stadium](stadium/README.md) — стадион, вариант 11.

Стек: Python 3.11+, Flask, SQLite и HTML-шаблоны Jinja. Каждый проект запускается отдельно и имеет свои зависимости и будущую базу данных.

В каждом проекте:

- `app.py` — запуск, маршруты и проверка ролей.
- `db.py` — подключение к SQLite и SQL-запросы.
- `database/schema.sql` — структура БД и демонстрационные данные.
- `templates/` — HTML-страницы.
- `static/style.css` — стили.
- `tests/` — тесты приложения.
- `pyproject.toml` — зависимости и настройки проекта.

Реализованы вход по ролям, поиск, заявки и выдача книг, управление расписанием, продажа и возврат билетов. База из пяти таблиц создаётся автоматически при первом запуске в `instance/` каждого проекта; последующие запуски сохраняют данные. Ключ сессий хранится там же.
