# Стадион

Самостоятельное приложение по варианту 11.

## Роли и функции

- Администратор: формирование расписания матчей.
- Кассир: продажа билетов и возврат проданных билетов.

## Структура

- `app.py` — запуск, маршруты и проверка ролей.
- `db.py` — подключение к SQLite и SQL-запросы.
- `database/schema.sql` — таблицы и демонстрационные данные.
- `templates/` — страницы входа, матчей и билетов.
- `static/style.css` — стили.
- `tests/` — тесты приложения.
- `pyproject.toml` — зависимости и настройки проекта.

Приложение должно взаимодействовать с собственной БД из 3–5 связанных таблиц. Доступ к функциям определяется ролью пользователя. Связанные записи выбираются с отображением понятных значащих полей; поиск использует критерии пользователя. Ошибки обработки данных отображаются понятными сообщениями.

## Запуск

Для запуска на http://127.0.0.1:5001 выполните из корня репозитория (Python 3.11+):

```powershell
# Windows (PowerShell)
cd stadium
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
python app.py
```

```bash
# Linux (Bash)
cd stadium
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python app.py
```

Демо-вход: `admin / admin123` — администратор, `cashier / cashier123` — кассир; БД создаётся автоматически в `instance/stadium.sqlite`.

## Проверка

Из папки `stadium` с активированным окружением:

```bash
python -m unittest discover -s tests -v
```
