# Стадион

Самостоятельное приложение по варианту 11.

## Роли и функции

- Администратор: формирование расписания матчей.
- Кассир: продажа билетов и возврат проданных билетов.

## Структура

- `app.py` — запуск, маршруты и проверка ролей.
- `db.py` — подключение к SQLite и SQL-запросы.
- `database/schema.sql` — таблицы и демонстрационные данные.
- `templates/` — страницы входа, матчей и билетов.
- `static/style.css` — стили.
- `tests/` — тесты приложения.
- `pyproject.toml` — зависимости и настройки проекта.

SQLite содержит 5 связанных таблиц: пользователи, команды, матчи, места и билеты. Время матчей — Ташкент (UTC+5), цены — в целых сумах. Продажа и возврат доступны до начала матча. Все кассиры работают с общим списком билетов. После первой продажи матч нельзя изменить или удалить, даже после возврата билета.

## Запуск

Для запуска на http://127.0.0.1:5001 выполните из корня репозитория (Python 3.11+):

```powershell
# Windows (PowerShell)
cd stadium
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
python app.py
```

```bash
# Linux (Bash)
cd stadium
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python app.py
```

Демо-вход: `admin / admin123` — администратор, `cashier / cashier123` — кассир; БД создаётся автоматически в `instance/stadium.sqlite`.

## Демонстрация

1. Под `admin` откройте «Расписание», добавьте будущий матч, проверьте изменение и удаление матча без продаж.
2. Под `cashier` найдите матч по команде, дате или наличию билетов, нажмите «Продать билет» и выберите место; в разделе «Билеты» найдите продажу и нажмите «Вернуть билет».

## Проверка

Из папки `stadium` с активированным окружением:

```bash
python -m unittest discover -s tests -v
```
