# Библиотека

Самостоятельное приложение по варианту 2.

## Роли и функции

- Библиотекарь: обработка заявок, выдача книг и приём возвращённых книг.
- Читатель: поиск доступных книг и подача заявки на получение книги.

## Структура

- `app.py` — запуск, маршруты и проверка ролей.
- `db.py` — подключение к SQLite и SQL-запросы.
- `database/schema.sql` — таблицы и демонстрационные данные.
- `templates/` — страницы входа, каталога и заявок.
- `static/style.css` — стили.
- `tests/` — тесты приложения.
- `pyproject.toml` — зависимости и настройки проекта.

SQLite содержит 5 связанных таблиц: пользователи, авторы, книги, заявки и выдачи. Читатель видит только свои заявки; библиотекарь — все. Заявка не резервирует книгу, наличие проверяется при выдаче. Повторная заявка запрещена, пока предыдущая ожидает обработки или экземпляр не возвращён.

## Запуск

Для запуска на http://127.0.0.1:5000 выполните из корня репозитория (Python 3.11+):

```powershell
# Windows (PowerShell)
cd library
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
python app.py
```

```bash
# Linux (Bash)
cd library
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python app.py
```

Демо-вход: `admin / admin123` — библиотекарь, `reader / reader123` — читатель; БД создаётся автоматически в `instance/library.sqlite`.

## Демонстрация

1. Под `reader` найдите книгу по названию, автору или наличию, нажмите «Подать заявку» и откройте «Мои заявки».
2. Под `admin` откройте «Заявки и выдачи»: выдайте книгу или отклоните заявку; после выдачи нажмите «Принять возврат».

## Проверка

Из папки `library` с активированным окружением:

```bash
python -m unittest discover -s tests -v
```
